# Архитектурные документы реализованной функциональности

В этом каталоге лежат архитектурные документы уже реализованной функциональности, по одному файлу на подсистему. Каждый описывает текущую реализацию так, как она устроена в коде: где лежат данные, публичный интерфейс, бизнес-логику, инварианты и известные ограничения. Источник истины — код. Если документ расходится с кодом, прав код, а документ нужно исправить. Требования и журнал решений по-прежнему ведутся в [`../architecture.md`](../architecture.md). Документы ссылаются на номера решений (A-номера).

## Указатель

- [cache.md](cache.md) — кеш превью T1/T2 (`core/blob`, `core/node`), планировщик предзагрузки (`core/prefetch`) и загрузчик показа (`core/show`), закрепления и бюджет.
