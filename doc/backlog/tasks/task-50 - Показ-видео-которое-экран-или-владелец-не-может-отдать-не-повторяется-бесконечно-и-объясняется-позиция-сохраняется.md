## Description

Ревью 2026-11-11 (doc/review-2026-11-11/video.md V2, V3, V6, V10, V11): неподдерживаемый экраном кодек (HEVC/HDR с iPhone) и нечитаемый оригинал (только в iCloud, удалён, доступ отозван) дают бесконечный LOAD раз в секунду с общей фразой на пульте — требование §2.3 architecture.md о плашке вместо чёрного экрана не выполнено. ## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Видео, которое экран не воспроизводит, после одного повтора перестаёт загружаться: экран получает постер, пульт называет причину (с кодеком, если он известен) и что сделать; «Воспроизвести» — ручная повторная попытка
- [ ] #2 Оригинал, который владелец не может прочитать, даёт постер и причину на пульте (отдельно — «оригинал не на устройстве»), в том числе для собственного видео хоста; причина владельца попадает в журнал хоста; LOAD не повторяется бесконечно
- [ ] #3 Позиция воспроизведения сохраняется: после переподключения к экрану, ручного «Воспроизвести» и повтора после ошибки видео продолжается с места остановки; короткий сбой владельца даёт один автоматический повтор
- [ ] #4 После конца видео экран показывает постер, «Воспроизвести» запускает видео сначала
- [ ] #5 Каждое изменение поведения сначала воспроизведено красным тестом; doc/adr и architecture.md (A56) обновлены
