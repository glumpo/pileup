## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
При последовательном просмотре следующий файл должен быть уже загружен, а прыжки по хронологии не должны ломать кеш. Правила зафиксированы в architecture.md, 6.2: окно из 20 элементов после курсора, дальше не грузим, вытеснение по самому раннему taken_at. Видео не предзагружается.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 После перехода курсора загружаются отсутствующие T2 из 20 следующих элементов в порядке хронологии; дальше окна загрузка не идёт
- [ ] #2 При превышении бюджета первым вытесняется элемент с самым ранним taken_at; текущий файл, окно и закреплённые файлы не вытесняются
- [ ] #3 С одного источника одновременно идёт не более 5 загрузок
- [ ] #4 Файлы недоступного источника помечаются ожидающими, остальные файлы окна грузятся дальше, к ожидающим загрузка возвращается с повторами
- [ ] #5 Логика покрыта тестами, включая прыжки вперёд и назад
<!-- AC:END -->
