## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
iPhone-источник перестаёт отвечать, когда гаснет экран. Пользователь хоста должен понять причину и иметь способ один раз забрать все превью, чтобы дальше не зависеть от этого телефона (architecture.md, 6.3).
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 При таймауте источника на хосте показывается подсказка с именем участника и советом разблокировать телефон
- [ ] #2 Кнопка «Загрузить всё с участника» загружает весь T2 этого участника, кнопка «Загрузить вообще всё» — весь T2 pile; видео не загружается
- [ ] #3 Перед загрузкой показываются оценка объёма и свободное место, во время — прогресс по участникам
- [ ] #4 Загруженное кнопками закрепляется и не вытесняется, пока пользователь не снимет закрепление
- [ ] #5 Если источник видео недоступен, на экране постер и подсказка, показ можно продолжить
<!-- AC:END -->
