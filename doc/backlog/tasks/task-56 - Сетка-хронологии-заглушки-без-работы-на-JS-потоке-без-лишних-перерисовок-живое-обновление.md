## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Ревью 2026-11-11 (doc/review-2026-11-11/photos.md P2, P8, P9; diagnosability.md D12): thumbhash декодируется в JS при каждом монтировании ячейки (замер без JIT: 6,6 мс на ячейку на x86; открытие сетки — 44 декодирования, скролл — одно на каждую новую ячейку) — требования «сетка открывается мгновенно» и «5000 превью скроллятся плавно» под угрозой. Открытие и закрытие просмотра перерисовывает все ячейки. Сетка — снимок: thumbhash и файлы, пришедшие позже, не видны без pull-to-refresh; у миниатюр нет повтора при ошибке; во время загрузки и до первой синхронизации написано «Пока нет файлов».
