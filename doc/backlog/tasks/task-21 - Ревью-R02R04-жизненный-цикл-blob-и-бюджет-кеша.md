## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Ревью 2026-11-09, пункты R02 (с R03) и R04. Вытеснение удаляет физический файл по хешу без учёта других ссылок (другой pile, закрепление, T1 с теми же байтами); удаление может проиграть гонку завершению загрузки; T2, загруженные через viewer, не попадают в бюджет; старые ревизии и удалённые файлы остаются на диске.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Физический blob удаляется только после снятия последней удерживающей ссылки; вытеснение в одном pile не ломает файл, нужный другому pile, закреплению или T1 с тем же хешем
- [ ] #2 Удаление во время загрузки не приводит к повторному появлению объекта; конкурентные запросы одного объекта выполняют одну загрузку
- [ ] #3 Любой полученный T1/T2 (viewer, показ, прогрев, ручная загрузка) учитывается в бюджете и вытесняется по общей политике без участия вызывающего кода
- [ ] #4 Удалённые файлы и старые ревизии очищаются
- [ ] #5 Каждая ошибка сначала воспроизведена красным тестом
<!-- AC:END -->
